# What is obsolete or unnecessary in the repository (audit, 2026-11-02)

**Scope.** Separate from `research-state-assessment.md`. This report is about *the repository*,
not the science: what can be deleted, archived, merged or corrected, and what only *looks* dead.
**Nothing has been deleted or moved by this audit.** Every row says what to do and what it costs.

**Method.** `git ls-files` (1,026 tracked files, 44 MB `.git`), sizes, a static import scan of
every module in `packages/*/src/sb/` against all `.py` files, notebooks and `apps/` tooling (a
heuristic: dynamic imports and `python -m` entry points can hide users, so every "unused" row
names the check to run before acting), notebook cell metadata (executed-cell counts), the registry
index, and the claims in `README.md` / `TODO.md` / `CLAUDE.md`.

**Categories.** **R** remove · **A** archive (finished; keep for the record, out of the working
tree) · **D** dormant (decision needed: finish or retire) · **F** fix text (stale or wrong, keep
the thing) · **K** keep (looks dead, is not).

Totals at a glance: removable code ≈ **2.4 k lines of Python + 1.4 k of TypeScript**; ≈ 6 MB of
tracked notebook output and 2.8 MB of generated graph files; **52 of 91 registry runs** are on a
retired split and 6 more are exact duplicates; **≈ 540 lines of `TODO.md`** (§2, §10) describe a
deprecated workstream.

## 7. Suggested order and effect

1. **Two-line wins:** 1.4 (`graphify-out`), 1.5 (vendored skill), 1.9, 5.7 → −5 MB tracked, no behaviour change.
2. **POPSIGN removal** (1.1, 1.2, 1.3, 1.7, 5.3, TODO §2/§10): tag first, then drop → ≈ −2.4 k lines of Python and −1.4 k of TypeScript, fewer
   default dependencies (mediapipe, opencv leave `uv sync`), −6 notebooks, ≈ −540 lines of TODO.
3. **Registry tidy** (2.1, 2.3, 2.4) after the BiLSTM swap (2.2): `index.csv` falls from 91 to ≈ 30 rows, and the leaderboard
   and registry become the same list.
4. **Text fixes** (4.2–4.4, 5.1, 5.2, 5.4, 5.5) so the README matches the code and TODO starts with the real next actions.
5. **Decide** 3.1–3.5 once the supervisor has seen the state report.

**Risks to guard.** Each removal should be a tagged commit, so `git checkout <tag>` restores it; run
`sb-docs --check`, `sb-sync status`, `ty check` and `npm test` (16 tests) after steps 2–3; and do not
touch `registry/checkpoints.manifest.json` by hand. The import scan is a heuristic: for any code row, `grep -rn
"<module>"` across `packages/ experiments/ apps/ ops/` before deleting.
