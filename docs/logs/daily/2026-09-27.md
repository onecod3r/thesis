## 1. Recognition v2: ASL-LEX-complete rule-based phonology, no pose (TODO §14, new)

Following the critique in `docs/reports/phonology-pipeline-proposal.md` (§12.9, filed 2026-09-26), the user
asked for two things built as a deliberately isolated workstream ("recognition_2") that never edits any
existing `sb.recognize` module: a rule-based engine covering all 18 ASL-LEX 2.0 phonological parameters from
hand+face landmarks only (no MediaPipe pose), validated against ASL-LEX's own ground truth on the 233/250
GISLR glosses that map into ASL-LEX; and a GISLR sentence dataset restricted to the same 233 glosses.

Built and run end to end (`packages/sb-recognize/src/sb/recognize/recognition2/`,
`experiments/recognition2/`): the full 18-parameter agreement table (`data/cache/gislr_aslex_rules/`) shows
coarse/binary parameters read far above chance (`ulnar_rotation` 0.855, `spread_change` 0.764,
`sign_type` 0.660 vs 0.2 chance, `selected_fingers` 0.469 vs 0.111 chance) while fine-grained ones and
anything needing pose sit near chance or are `NOT_COMPUTABLE` (`second_minor_location` 0% coverage,
`non_dominant_handshape` 0.4% coverage). The ASL-LEX-restricted sentence dataset built cleanly: 6,335
sequences, 0 failed, 100/100 round-trip checks exact. Details: TODO §14, `README.md` Datasets/Models.
